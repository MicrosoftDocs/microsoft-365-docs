# Microsoft 365 Multi-Geo Commitments

For [eligible customers](microsoft-365-multi-geo.md#licensing) that purchase _Multi-Geo_, Microsoft makes commitments to store in-scope customer data in the applicable _Geography_, including (a) in the _Default Geography_ for the _Tenant_ and (b) in a _Satellite Geography_ for user data (as determined by _PDL_). Refer to Table 1 in [Overview and Definitions](m365-dr-overview.md#table-1-definitions-and-terms) for more information.

The commitments are specified as follows.

## Exchange Online

The following customer data is stored in the applicable _Geography_:

- Exchange Online mailbox content (e-mail body, calendar entries, and the content of e-mail attachments)

## SharePoint/OneDrive

The following customer data is stored in the applicable _Geography_:

- SharePoint site content and the files stored within that site and files uploaded to OneDrive

## Microsoft Teams

The following customer data is stored in the applicable _Geography_:

- Microsoft Teams chat messages (including private messages, channel messages, meeting messages and images used in chats), and, for customers using Microsoft Stream (on SharePoint), meeting recordings

## Microsoft 365 Copilot and Copilot Chat

The following customer data is stored in the applicable _Geography_:

- "Content of Interactions" such as the user's prompt and the response from Microsoft 365 Copilot or Microsoft 365 Copilot Chat, including citations to any information used to ground Microsoft 365 Copilot's response.
