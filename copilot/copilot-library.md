# Microsoft 365 Copilot Library

## What is Copilot Library?

Copilot Library is the central hub for the content you create when using Copilot Chat, and Create in the Microsoft 365 Copilot app on the web, Windows desktop, Mac desktop, and mobile platforms. Copilot Library consolidates user-generated images, pages, infographics, and stories that make these files easily accessible in one place. Copilot Library is visible to users with Copilot Chat eligibility and adapts its tabs based on admin policy settings.

## Find images and pages with Copilot Library

**To find images and pages with Copilot Library:**

1. Sign into [microsoft365.com](https://microsoft365.com/) with your work or school account. You should see your name and picture at the bottom-left corner of the screen.
1. Select Copilot Library.
1. Select one of the following:
    1. Images: Select the All types dropdown to filter and view your infographics, stories, posters, and banners.
    1. Pages: Display the pages you made or use the filter to access pages that were shared with you.

> [!NOTE]
> If your Copilot Library is empty, you can start adding to your Copilot Library by [creating new images](https://support.microsoft.com/topic/get-started-with-microsoft-365-copilot-create-6e0c616d-69fb-42f2-a4cb-c59e006ec4f5) or [building Copilot Pages](https://support.microsoft.com/topic/get-started-with-microsoft-365-copilot-pages-6674bd51-9ff5-42c4-9256-44d9428a726f).

## Copilot Library policy settings and eligibility logic

Copilot Library's visibility logic uses the following to determine Copilot Library eligibility:

- Copilot Chat eligibility: Only users with Copilot Chat eligibility see Copilot Library in the left navigation. If eligibility is revoked, Copilot Library is hidden from the left navigation.
- Image and Page creation policies:
    - If both Image Creation and Page Creation are disabled in OCPS (Office Cloud Policy Service), Copilot Library is hidden.
    - If only Image Creation is disabled, the Images tab in Copilot Library is hidden. If only Page Creation is disabled, the Pages tab in Copilot Library is hidden.

For more information about the Page creation admin setting, see [Manage Copilot Pages and Copilot Notebooks in your organization](/microsoft-365/loop/cpcn-admin-configuration).

## Supported file formats

The following file formats are supported in Copilot Library:

- Pages: Both `.loop` (legacy Copilot Pages) and `.page` (new Copilot Pages) formats are supported in Copilot Library.
- Images: All images created using Create in Microsoft 365 Copilot or Copilot Chat are supported. Images can be downloaded directly from Copilot Library as a .jpeg.

## Frequently asked questions

### How are items sorted and searched?

Images are sorted by date created, and Pages are sorted by last modified date and searchable by title.

### What happens to the Pages in the left navigation panel?

As Copilot Library is released to customers, users will see the Copilot Library entry point in the left Navigation instead of the Page list. All your created pages and images are found in Copilot Library.

### What licenses are required for Copilot Library access?

Users must have Copilot Chat eligibility, but not necessarily a Copilot license. For more information about licensing, see [Decide which Copilot is right for you](../copilot/which-copilot-for-your-organization.md) and [How Copilot Chat works with and without a Microsoft 365 Copilot license](https://support.microsoft.com/topic/how-copilot-chat-works-with-and-without-a-microsoft-365-copilot-license-5810b659-fbe0-48ee-9fe6-d731fe86cdeb).

### Where is Copilot Library available?

Copilot Library is available in the Microsoft 365 Copilot app on web, Windows desktop, Mac desktop, and mobile platforms. Integration with Microsoft Teams and Microsoft Word is planned for future releases.

### Does Copilot Library require additional storage?

No, Copilot Library doesn’t require any additional storage; Copilot Library is simply a view to find pages and images you created.

### Where can I learn more about my data in Copilot Library and privacy with Copilot?

Copilot and Microsoft 365 are built on Microsoft's comprehensive approach to security, compliance, and privacy.

For more information about privacy, see the following information:

- If you're using Microsoft 365 Copilot in your organization (with your work or school account), see [Data, Privacy, and Security for Microsoft 365 Copilot](../copilot/microsoft-365-copilot-privacy.md).
- If you're using Copilot in Microsoft 365 apps for home (with your personal Microsoft account), see [Copilot in Microsoft 365 apps for home: your data and privacy](https://support.microsoft.com/office/copilot-in-microsoft-365-apps-for-home-your-data-and-privacy-6f0d8d80-f4bb-4c9f-989e-64a4adfd62e5).
